NOT DEPLOYED — run locally using docs/setup-guide.md

The project runs fully locally via Docker Compose. No cloud deployment is required.

To run it:
  git clone https://github.com/ChetanSenta/bob-ai-hackathon-CodeMasters.git
  cd bob-ai-hackathon-CodeMasters
  cp .env.example .env
  docker compose up --build

Services:
  Frontend (React)   → http://localhost:3000
  Backend API        → http://localhost:8000
  API Docs           → http://localhost:8000/docs
  PostgreSQL         → localhost:5432 (internal)

See docs/setup-guide.md for full setup instructions including the no-Docker (SQLite) path.
